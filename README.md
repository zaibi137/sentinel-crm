## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn
- Angular CLI (`npm install -g @angular/cli`)

### Installation

```bash
# Clone the repo
git clone https://github.com/zaibi137/sentinel-crm.git
cd sentinel-crm

# Install dependencies
npm install

# Start dev server
ng serve
